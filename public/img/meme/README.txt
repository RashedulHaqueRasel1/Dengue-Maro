নিজের মিম ছবি যোগ করার নিয়ম
================================
1. ছবিটা (jpg / png / webp) এই img/meme/ ফোল্ডারে রাখুন, যেমন: dipjol1.jpg
2. memes.json ফাইলে নাম আর ক্যাপশন লিখুন, যেমন:

[
  { "file": "dipjol1.jpg", "caption": "মশা ভিলেন হাজির! 😈" },
  { "file": "dipjol2.jpg", "caption": "এই থাপ্পড় আমি জীবনে ভুলবো না" }
]

গেমে কম্বো, মশা সর্দার মারা, কামড় আর খেলা শেষের সময় এগুলো মামার মিমের সাথে
এলোমেলোভাবে দেখাবে। শুধু সেই ছবিই দিন যেটা ব্যবহারের অধিকার আপনার আছে।
