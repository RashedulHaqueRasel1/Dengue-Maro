দেয়ালের ফ্রেমে নিজের মিম ছবি বসানোর নিয়ম
=========================================
1. ছবিটা (jpg / png / webp) এই img/wall/ ফোল্ডারে রাখুন, যেমন: dipjol-aay-hay.jpg
2. wall.json ফাইলে নাম আর ক্যাপশন লিখুন (প্রথম দুইটা দেয়ালে দেখাবে):

[
  { "file": "dipjol-aay-hay.jpg", "caption": "আয় হায়! মশা!" },
  { "file": "dipjol-moja-nao.jpg", "caption": "মজা নাও?" }
]

- caption না চাইলে "" দিন (ছবিতে আগে থেকেই লেখা থাকলে)।
- মুখ ফ্রেমের বাইরে কেটে গেলে "focusY": 0.2 (উপরে) থেকে 0.8 (নিচে) দিয়ে ঠিক করুন।
- wall.json খালি ([]) থাকলে মামার ছবি দিয়ে মজার ফ্রেম দেখাবে।
- শুধু সেই ছবিই দিন যেটা ব্যবহারের অধিকার আপনার আছে।
