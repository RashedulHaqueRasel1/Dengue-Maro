# ডেঙ্গু থাপ্পড় বাজ 👋🦟 · Dengue Slap Master

> **মশা মারতে কামান লাগে না, একটা থাপ্পড়ই যথেষ্ট!**  
> ঘুমন্ত মামাকে এডিস মশার কামড় থেকে বাঁচানোর একটি মজার বাংলা ব্রাউজার গেম। সচেতনতা বাড়াতে এবং আনন্দ দিতে তৈরি।

---

## 🎮 গেম সম্পর্কে

খাটে ঘুমিয়ে আছেন মামা, আর চারপাশ থেকে ছুটে আসছে ডেঙ্গু মশা! মামাকে কামড়ানোর আগেই স্ক্রিনে ট্যাপ করে থাপ্পড় মেরে মশাদের থামাতে হবে। সাথে রয়েছে দেশীয় মজার মিম সাউন্ড, কম্বো বোনাস, পাওয়ার-আপ এবং গেম শেষে নিজের স্কোর দিয়ে বন্ধুদের চ্যালেঞ্জ করার সুযোগ।

🔗 **সরাসরি খেলুন:** [dengue-maro.pages.dev](https://dengue-maro.pages.dev)

## ✨ মূল ফিচারসমূহ

- 🦟 **মজার গেমপ্লে:** ক্যানভাসে হ্যান্ড-ড্রন ঘর ও চরিত্র। নরমাল, ফাস্ট, মোটকু এবং শক্তিশালী **বস মশা** (মারতে ৬ থাপ্পড় লাগে)।
- ⚡ **পাওয়ার-আপ:** মশার গতি কমাতে **কয়েল**, কামড় থেকে বাঁচতে **ক্রিম**, চারপাশ সাফ করতে **ইলেকট্রিক ব্যাট**, আর লাইফ ফিরে পেতে **ডাবের পানি**।
- 💧 **লার্ভা নিধন:** জানালার টবে জমা পানিতে ট্যাপ করে লার্ভা নষ্ট করা যায়, যাতে বাইরে থেকে মশার ঝাঁক আসা সাময়িক বন্ধ থাকে।
- 🔊 **দেশীয় মিম সাউন্ড:** খেলা শুরু থেকে গেম ওভার পর্যন্ত সিচুয়েশন অনুযায়ী জনপ্রিয় ৩৮টি বাংলা/হিন্দি মিম সাউন্ড।
- 🏆 **গ্লোবাল লিডারবোর্ড:** কোনো অ্যাকাউন্ট ছাড়া স্বয়ংক্রিয়ভাবে নিজের ডিভাইসের সেরা স্কোর সংরক্ষণ ও র‍্যাঙ্ক দেখার সুবিধা।
- 📰 **"দৈনিক মশারি" পেপার:** ম্যাচ শেষে স্কোর, র‍্যাঙ্ক ও মজার ব্রেকিং নিউজসহ স্বয়ংক্রিয় ডিজিটাল পত্রিকা তৈরি হয়।
- 📸 **শেয়ার কার্ড:** পত্রিকার মতো ছবি এক ক্লিকে ডাউনলোড ও সোশ্যাল মিডিয়ায় সরাসরি প্রিভিউ লিংক শেয়ারের সুবিধা।

## 🛠️ ব্যবহৃত প্রযুক্তি

- **Frontend:** HTML5, CSS3, Vanilla JavaScript (কোনো ভারী ফ্রেমওয়ার্ক ছাড়া সুপারফাস্ট)।
- **Graphics & Audio:** HTML5 Canvas (2D) এবং Web Audio API।
- **Backend & Edge:** Cloudflare Pages এবং Cloudflare Workers।
- **Database:** MongoDB Atlas (লিডারবোর্ড স্কোর, ভিজিট কাউন্টার ও শেয়ার কার্ডের জন্য)।

## 📁 সহজ ফাইল পরিচিতি

```
Dengue-maro/
├── public/                 # মূল সাইট (HTML, CSS, JS, ছবি ও সাউন্ড ফাইল)
│   ├── js/                 # গেমের লজিক (main.js), গ্রাফিক্স (art.js), অডিও (audio.js)
│   ├── img/                # চরিত্র, দেয়ালের মিম ফ্রেম ও পত্রিকার গ্রাফিক্স
│   └── sounds/             # ইন-গেম সব মিম সাউন্ড এফেক্ট
├── api/                    # ব্যাকএন্ড API (লিডারবোর্ড, ভিজিট কাউন্ট ও শেয়ারিং)
├── functions/              # Cloudflare Pages রাউটিং ফরোয়ার্ডার
└── wrangler.jsonc          # ক্লাউডফ্লেয়ার ডেপ্লয়মেন্ট কনফিগারেশন
```

## 🚀 লোকালি চালানোর নিয়ম

আপনার কম্পিউটারে **Node.js** ইনস্টল থাকলে খুব সহজেই এটি রান করতে পারবেন:

```bash
# ১. রিপোজিটরি ক্লোন ও ডিপেনডেন্সি ইনস্টল
npm install
cd api && npm install && cd ..

# ২. লোকাল ডেভ সার্ভার চালু করুন (দুইটি আলাদা টার্মিনালে)
# টার্মিনাল ১ (API Worker):
cd api && npm run dev

# টার্মিনাল ২ (Frontend Game):
npm run dev
```

ব্রাউজারে `http://localhost:8787` ওপেন করলেই গেমটি চালু হয়ে যাবে।

> **টিপ:** আপনি যদি এপিআই/ডাটাবেস ছাড়াই শুধু গেমপ্লে দেখতে চান, তবে সরাসরি `public/` ফোল্ডারটি যেকোনো সাধারণ লাইভ সার্ভারে ওপেন করলেই চলবে।
